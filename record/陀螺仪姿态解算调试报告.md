# 陀螺仪姿态解算调试报告

**日期：** 2026-05-13
**目标：** 完成 STM32F411 无人机的陀螺仪姿态解算，让 Mahony AHRS 正确输出 Roll/Pitch/Yaw 欧拉角
**输出方式：** 纯串口 printf（USART1, 460800 baud）

---

## 一、初始状态

### 已有代码
- Mahony AHRS 算法完整实现（`411/Control/AHRS_Mahony.c`）
- 传感器数据通路完整：sensor_task → 低通滤波 → 队列 → posture_task → Mahony
- 磁力计校准函数已实现（`411/Hardware/QMC5883P.c`）但从未被调用
- PID 结构体存在但控制逻辑未实现

### 阻断问题
1. **采样周期不匹配**：`s_sample_period = 0.002f`（500Hz），但 posture_task 以 50Hz 调用，四元数积分差 10 倍
2. **无姿态输出**：posture_task 的 euler 角 printf 被注释掉了
3. **IMU 分辨率未赋值**：`accel_curr_resolution` 和 `gyro_curr_resolution` 初始化为 0，从未被赋值
4. **printf 不支持 float**：newlib-nano 默认不启用 `%f` 格式化
5. **磁力计未校准**：校准参数为默认单位矩阵

---

## 二、修复过程

### Step 1：修复采样周期 + 添加串口输出

**改动文件：**
- `411/Control/AHRS_Mahony.h` — 新增 `mahony_set_sample_period()` 声明
- `411/Control/AHRS_Mahony.c` — 新增函数实现
- `411/Core/Src/freertos.c` — posture_task 中调用 `mahony_set_sample_period(0.02f)`，取消注释 euler 角 printf（改为 `ATT:%.2f,%.2f,%.2f` 格式），注释掉 sensor_task 的干扰 printf

**结果：** 编译烧录后串口输出 `ATT:,,`（空值）→ 发现 printf 不支持 float

### Step 1b：启用 printf float 支持

**改动文件：** `411/platformio.ini`

在 build_flags 中添加：
```
-Wl,-u,_printf_float
```

**结果：** 串口输出 `ATT:-0.15,-0.12,-0.06` 等数值，但持续漂移

### Step 2：添加传感器诊断

在 posture_task 中添加每秒一次的诊断 printf，输出 ACC/GYR/MAG 数据。

**发现：** `ACC(g):0.000,0.000,0.000` — 加速度计坐标变换后全是 0！

**根因：** `ICM42688_init()` 跳过了 `ICM42688_CalibrateGyroAndWriteOffset()`（因为 offset 写回导致寄存器异常），但 resolution 赋值也被连带跳过了。

### Step 3：修复 IMU 分辨率

**改动文件：** `411/Hardware/ICM42688.c`

在 `ICM42688_init()` 末尾添加：
```c
accel_curr_resolution = 8.0f / 32768.0f;      // +/-8G
gyro_curr_resolution = 2000.0f / 32768.0f;     // +/-2000dps
```

**结果：** ACC 数据正确（平放时 Z≈1.0g），Roll/Pitch 收敛到近 0，但 Yaw 持续漂移（~0.7°/s）

### Step 4：磁力计校准

在 main.c 启动序列中临时添加 `QMC_Calibrate_Full(30)` 调用。

**校准操作（人工执行）：**
1. 拿起无人机，远离电脑/金属物体 1 米以上
2. 正面朝上，水平缓慢转一圈（360°）
3. 翻过来（反面朝上），水平缓慢转一圈
4. 右侧立起来（右边缘朝下），竖着转一圈
5. 左侧立起来（左边缘朝下），竖着转一圈
6. 机头朝下，竖着转一圈
7. 随意做几个 8 字形运动

**第一次校准参数（质量：较差，软铁畸变 106.8%）：**
```c
offset_x = -756.50, offset_y = 274.50, offset_z = 1250.50
m00 = 1.2636, m11 = 1.9435, m22 = 0.5903
```

**结果：** Yaw 漂移从 0.7°/s 降到 ~0.03°/s，方向修正生效

### Step 5：坐标系验证 + Pitch 方向修复

通过人工操作无人机（右侧抬起、前端抬起、水平旋转）验证坐标系方向。

**发现问题：** 前端抬起（nose up）时 Pitch 输出为负值（-42°），应该是正值。

**修复过程：**
1. 第一次尝试翻转 `acc_y_sign` 和 `gyro_y_sign` → 反而搞坏了 Roll，Pitch 仍为负
2. 最终方案：恢复原始坐标变换，在 `quaternion_to_euler()` 中对 pitch 结果取反

**改动文件：** `411/Control/AHRS_Mahony.c`

```c
*pitch = -asinf(sinp) * RAD2DEG;     // 原来无负号
*pitch = -copysignf(...);              // 同样取反
```

**验证结果：**

| 动作 | Roll | Pitch | Yaw | 判断 |
|------|------|-------|-----|------|
| 右侧抬起 | +69° | ~0° | — | 正确 |
| 前端抬起 | ~0° | +29° | — | 正确 |
| 水平旋转 | ~0° | ~0° | 112°→170° | 正确 |

### Step 6：重新校准磁力计（第二次，质量更好）

距离上次校准位置更远，重新执行 30 秒校准。

**第二次校准参数（质量：一般，软铁畸变 24%）：**
```c
offset_x = 34.50, offset_y = 445.00, offset_z = -12.00
m00 = 1.1112, m11 = 1.0611, m22 = 0.8638
```

## 五、使用方法

### 串口监控
```bash
cd code/411
bash scripts/flash_monitor.sh 6       # 捕获 6 秒
python3 -c "import serial, time
s = serial.Serial('/dev/cu.usbmodem11403', 460800, timeout=1)
while True: print(s.readline().decode('ascii', errors='ignore').strip())
"
```

### 网页可视化
```bash
open 411/scripts/attitude_viewer.html   # Chrome 打开，点击 Connect Serial
```

### 重新校准磁力计
如需重新校准，在 `main.c` 中将校准参数块替换为 `QMC_Calibrate_Full(30);`，烧录后在串口提示下旋转无人机 30 秒，校准完成后将输出的参数写回代码。

## 六、已知限制

1. **磁力计校准质量一般**（软铁畸变 24%），无人机电机的磁场干扰较大，校准需远离金属
2. **校准参数未持久化**到 Flash，每次烧录新固件需确认校准参数未丢失
3. **Pitch 取反是输出层修正**，内部四元数未变，后续 PID 控制需要注意
4. **启动时 Yaw 需 5-10 秒收敛**到磁航向，初始几秒 yaw 值不准确
5. **传感器低通滤波系数**未优化（gyro α=0.4, accel α=0.15, mag α=0.08）
